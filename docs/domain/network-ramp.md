# New Joiner Network Ramp v0.1

## Purpose

Reduce the initial internal-network disadvantage that is independent of capability. Applies to both graduate and experienced hires.

## Graduate journey

BELONG -> LEARN/CONNECT -> EXPAND -> ACTIVATE.

Early recommendations emphasize cohort/team/buddy/nearby role models and then deliberately broaden beyond the cohort. A cohort-heavy first month is expected, not a poor-health signal.

## Experienced-hire journey

LAND/CONNECT -> EXPAND -> ACTIVATE internally; user-facing phase vocabulary may be unified with the graduate journey. Professional-fit and internal-context connections can be weighted earlier because external experience may already be strong while internal reach is thin.

## Recommendation inputs

Hire context + Networking Style + Actual Network + User Goal/context. Hire type is only an initial prior.

## Network readiness

Do not declare readiness solely because 180 days elapsed. Use meaningful relationships, reach/support, ramp progress, and (later) perceived support. Time to Network Readiness is a long-horizon program KPI.

## Network giving

Existing employees may receive accessible "welcome" recommendations and introduction opportunities so the burden of networking does not fall only on new joiners.
