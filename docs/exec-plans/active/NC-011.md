# NC-011 — Analog Interaction Capture v0.1

**State:** Ready for implementation — specification Review Gate approved on 2026-08-09; no code
changes started.

## Objective

Implement the frozen fast factual 1:1 analog-contact flow from Person Detail through an atomic,
idempotent `POST /api/v1/interactions` write. Persist one immutable self-reported event, re-derive
only the affected canonical relationship pair with accepted `relationship-v0.1.0`, then refresh the
detail/network experience without global graph re-layout.

## Frozen inputs and boundaries

- Current person is resolved only by the server; the client submits one `otherPersonId`.
- Types are exactly `OFFICE_CHAT`, `COFFEE`, `LUNCH`, `DINNER`, `COMMUNITY`, `ACTIVITY`, `OTHER`.
- Duration is required and exactly `SHORT`, `MEDIUM`, or `LONG`; neither type nor duration defaults.
- `occurredAt` defaults in the web client, is aware/UTC-normalized, at most 30 days old, and not
  future-dated.
- The server fixes channel `ANALOG`, source `SELF_REPORTED`, confidence `1.0`, participant count `2`,
  creator as current user, and initiator as unknown.
- `(currentPersonId, clientRequestId)` is represented by existing source/external provenance for
  durable idempotency. Same payload replays; different payload conflicts.
- The accepted relationship formula/configuration and model version do not change.
- No multi-person capture, edit/delete, free text, `また話したい`, user correction,
  recommendation/Home/Health/Ramp, inferred/imported reconciliation, connector, production SSO,
  notification, offline, or formula-calibration work.

## Layering and atomicity decisions

- FastAPI routers translate HTTP only. The application command owns validation/orchestration;
  repositories own persistence; `RelationshipEngine` remains pure domain logic.
- The database transaction contains idempotency resolution, event/participant insert, pair-only fact
  and authorized-context read, profile derivation/upsert, and commit.
- Any failure rolls back both source and derived writes. Replays perform no second insertion or
  recalculation. Unrelated profiles must remain unchanged.
- The response describes only the accepted interaction fact and replay status. Refetched read models
  are the source for relationship labels/timeline/graph; numeric relationship components stay hidden.
