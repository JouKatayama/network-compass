# My Network Screen v0.1

The graph occupies roughly 65–75% of the working surface and is the product's core screen.

## Vertical Slice 001 required controls

- graph canvas
- search
- 1-hop / 2-hop affordance
- zoom/pan
- Fit
- Center on me
- Person selection
- Person expand
- right-side Person Detail drawer
- loading/error states

Relationship/organization semantics should be visible without showing raw numeric relationship scores.

The default graph must make these fixture states visible in one demo: strong/active edge, weak edge, dormant edge, 2-hop teaser, more than one organization cluster. Recommendation rings are not required until NC-008/009 if no recommendation engine exists yet.
