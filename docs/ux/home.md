# Home Screen v0.1 — Later Vertical Slice

Home exists to create a reason to open Network Compass, not to become an analytics dashboard.

Target order: three people to remember/know, 3–5 network updates, short qualitative network insight. New joiners receive ramp-oriented wording such as `今週、知っておくと良さそうな人`; established employees use softer reconnect wording such as `今週、思い出してほしい人`.

Recommendation cards show human-readable reasons/context, never recommendation score. If no high-quality recommendation exists, show none rather than manufacturing three weak suggestions.

**Not part of NC-001 or Vertical Slice 001.**
