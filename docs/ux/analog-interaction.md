# Analog Interaction Capture v0.1 — Later Vertical Slice

Goal: capture a meaningful offline/social contact in <=10 seconds.

Flow: select one or more people -> choose Office Chat/Coffee/Lunch/Dinner/Community/Activity/Other -> optional rough depth (`少し / しっかり / 長く`, optionally `また話したい`) -> review/save.

The frontend never sets evidence confidence directly; the server derives it. Duplicate/inferred-event handling must strengthen or reconcile evidence rather than blindly double-counting.

**Not part of NC-001 or Vertical Slice 001.**
