# ADR-008: Dark-first semantic theme

**Status:** Accepted

## Context

A dark surface supports subtle graph edges/territories and the desired enterprise visual direction.

## Decision

Implement dark theme first using semantic design tokens, not hard-coded component colors.

## Consequences

The repository and implementation must preserve this decision unless a replacement ADR is accepted. Prefer the simplest implementation consistent with the decision and product/privacy specifications.

## Reconsider when

Add light theme through tokens later.
