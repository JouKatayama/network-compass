# ADR-007: Desktop-first graph experience

**Status:** Accepted

## Context

Graph exploration benefits from a larger canvas; mobile is better suited to actions/capture.

## Decision

Optimize v0.1 primary UX for desktop while avoiding unnecessary touch breakage.

## Consequences

The repository and implementation must preserve this decision unless a replacement ADR is accepted. Prefer the simplest implementation consistent with the decision and product/privacy specifications.

## Reconsider when

Add deliberate mobile action/capture experience after core desktop behavior validates.
