# Architecture Decision Records

Accepted MVP decisions:

- ADR-001 PostgreSQL first; no Neo4j
- ADR-002 Sigma.js for graph rendering
- ADR-003 Modular monolith
- ADR-004 Rule-based recommendation first
- ADR-005 Interaction events as relationship evidence source
- ADR-006 Personal Graph Projection instead of full graph
- ADR-007 Desktop-first graph experience
- ADR-008 Dark-first semantic theme
- ADR-009 OpenAPI as API-contract source after implementation
- ADR-010 pnpm workspace + Python backend tooling split for monorepo

Any conflicting architectural change requires a new ADR proposal.
