# Documentation Index

This directory is the repository system of record. When documents conflict, use the more specific accepted specification/ADR and report the conflict rather than guessing.

## Product

`product/` defines why the product exists, MVP boundaries, principles, personas, and success measures.

## Domain

`domain/` defines canonical entities, interaction/relationship/recommendation models, Network Health, and Network Ramp.

## UX

`ux/` defines user journeys, information architecture, screen states, graph behavior, and P0 surfaces.

## Architecture

`architecture/` defines the modular-monolith design, API/data boundaries, privacy/security rules, repository structure, and ADRs.

## Data

`data/` defines deterministic synthetic datasets and hero fixtures.

## Testing

`testing/` defines Vertical Slice 001 acceptance criteria, testing strategy, and hero E2E behavior.

## Issues

`issues/` is the ordered implementation backlog NC-001 through NC-010.

## Codex

`codex/` defines the execution prompt template, first-task prompt, and review gates.

## Execution plans

`exec-plans/` contains active/completed implementation plans. NC-001 starts in `exec-plans/active/NC-001.md`.
