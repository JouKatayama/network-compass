# KPI Model v0.1

## MVP North Star — Incremental Relationship Activation (IRA)

The desired effect is contact that likely would not have happened without Network Compass.

Conceptually:

`IRA = P(Contact | Recommended) - P(Contact | Holdout)`

MVP telemetry prepares for causal evaluation; the synthetic implementation does not need a production experimentation platform.

## New Joiner metrics

Primary long-horizon ramp metric: **Time to Network Readiness** — time until a person can identify and access useful internal support/reach, adjusted to joiner context.

Useful leading measures include non-cohort meaningful connections for graduates, cross-unit/expertise introductions for experienced hires, perceived network support, and meaningful recommendation activation.

## Network Health

Use a multi-dimensional profile, not a single user-facing score: Activation, Depth, Reach, Diversity, Reciprocity, Renewal, with Resilience as hidden analysis. Compare to personalized target ranges rather than maximizing every dimension.

## Long-term business outcomes

Potential downstream outcomes: faster expert access, knowledge sharing, cross-unit collaboration, staffing/career mobility, introductions, proposal/project participation, and network-attributed opportunities. These are lagging indicators, not the MVP home experience.
